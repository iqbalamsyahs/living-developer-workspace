## Body
CMMS is an internal enterprise application used by maintenance teams to manage physical assets, plan preventive maintenance, and track work orders end to end.

I joined the frontend team in late 2024 and owned several modules from API integration to UI: the operational dashboard, preventive maintenance with seasonal frequency rules, asset–location relationships, and organization/security management.

Server state is handled with TanStack Query, shared app state with Redux Toolkit, and complex forms with Formik and Yup validation. Later I built a reusable attachment upload component adopted across multiple modules.

Internal enterprise app — screenshots use sanitized data; source code and live access are not public.
