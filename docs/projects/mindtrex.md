## Body
Mindtrex is an e-learning platform where learners follow lessons, answer interactive questions, and take assessments.

I built the learner web app on my own, from project setup to the full learning flow: course list, instructions, theory content, question sessions with multiple-choice and fill-in-the-blank types, and assessment results with grading. Authentication covers sign-in, OTP verification, and password reset.

The stack is React with Redux Toolkit for state, React Router for navigation, and Bootstrap/Reactstrap with Sass for styling.
